# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

## 未平隔离原因码与策略

隔离原因不是自由文本，而是有限原因码；每个原因码绑定一个互斥策略，策略落库为**原因码策略表**（`quarantine_policies`，每码一行）：

| 原因码 | 含义 | 默认策略 |
| --- | --- | --- |
| `NO_ORIGINAL` | 无原单 | 自动可再配 |
| `ACCOUNT_MISMATCH` | 账户不一致 | 需确认后可再配 |
| `OVER_EXCESS` | 超额 | 永久拒绝 |
| `AMOUNT_INVALID` | 金额非法 | 永久拒绝 |
| `UNCLASSIFIED` | 旧自由文本无法映射的兜底 | 永久拒绝 |

- 归并每轮都会复扫「未平」隔离，按**当前**策略表执行：自动可再配直接进入配平；需确认项无确认标记不配平；永久拒绝永不改余额。
- 确认标记物化为 `quarantine_confirmations`（隔离项唯一、含确认人与确认时策略快照），可审计、不可重复确认。
- 隔离行同时保存 `reason_code` 与 `policy_at_quarantine` 快照；列表展示的是策略表当前值，两者都在未平隔离页可见。
- 策略执行与配平在同一事务内：任一失败整体回滚，并落一条「失败」归并运行。
- 报告（归并运行与净额互证）按原因码分桶，分桶计数与隔离、策略表同源现算。

页面：未平隔离（原因码 + 策略 + 登记确认）/ 隔离策略（维护策略表）。**不是**质检签发，**不是**工单审批流。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 隔离策略 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
